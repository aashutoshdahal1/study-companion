🔍 Find My Data - Manual Inspection Guide

⚠️ Important: Your PDF notes data should be stored in your browser's IndexedDB. Let's help you find it manually.

📱 Browser Developer Tools Method

Step 1: Open Developer Tools
• Chrome/Edge: Press F12 or Ctrl+Shift+I (Windows) / Cmd+Option+I (Mac)
• Firefox: Press F12 or Ctrl+Shift+K (Windows) / Cmd+Option+K (Mac)
• Safari: Enable Developer Menu in Preferences, then Cmd+Option+I
Step 2: Go to Application/Storage Tab
• Chrome/Edge: Click "Application" tab → "Storage" → "IndexedDB"
• Firefox: Click "Storage" tab → "IndexedDB"
• Safari: Click "Storage" tab → "IndexedDB"
Step 3: Find StudyCompanionDB
Look for a database named "StudyCompanionDB" in the list
Step 4: Check the Stores
Expand StudyCompanionDB and look for these stores:
• docs - Your PDF documents
• notes - Your notes content
• workspaces - Workspaces
• blobs - File data
• flashcards - Flashcard data
Step 5: Examine the Data
Click on each store to see the data inside. Your PDF notes should be in the 'docs' and 'notes' stores.

🌐 Browser-Specific Instructions

Chrome/Edge:
1. Right-click → "Inspect"
2. Go to "Application" tab
3. Expand "IndexedDB"
4. Click "StudyCompanionDB"
Firefox:
1. Right-click → "Inspect Element"
2. Go to "Storage" tab
3. Expand "IndexedDB"
4. Click "StudyCompanionDB"
Safari:
1. Develop → Show Web Inspector
2. Go to "Storage" tab
3. Expand "IndexedDB"
4. Click "StudyCompanionDB"
